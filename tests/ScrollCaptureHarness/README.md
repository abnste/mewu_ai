# 长截图现场验收窗口

这是完全离线、无用户数据、无自动化输入的 WPF 测试页面，不随产品发布。
运行 `dotnet run --project tests/ScrollCaptureHarness` 后，通过鼠标和截图覆盖层验证：

- 从第 4 张彩色卡片附近开始，进入长截图后无需额外点击底层窗口即可滚动。
- 单格、连续三格向下滚轮，随后向上滚动，预览逐步拼接；反向回到已截范围不重复增长。
- 页面平滑滚动总时长 260ms，用来暴露旧版 500ms 轮询加 280ms 延迟造成的漏帧。
- 底层窗口有焦点时按 Esc，仍应取消长截图、恢复选区、长截图和录屏按钮。
- 完成后保持原图比例；复制/保存的像素高度与采集进度一致。

顶部显示真实滚动偏移。若画面偏移没有改变，应排查焦点/输入路由，而非放宽图像匹配阈值。

2026-09-04 现场回归：175% 缩放，1415 × 900 物理像素选区；从偏移 1800 DIP 开始，向下三格到 2520 DIP，长图为 2160px；向上三格回到 1800 DIP，高度仍为 2160px；继续向上一格到 1560 DIP，增长为 2580px。保存 PNG 实际尺寸为 1415 × 2580。再次进入长截图后，将 Esc 发给下层验收窗口，覆盖层成功取消并恢复长截图与录屏按钮，既有长图保留。此测试使用 Debug 显式防捕获验收开关，图中的控件边缘不代表 Release 捕获结果。
