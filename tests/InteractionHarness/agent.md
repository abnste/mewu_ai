# 覆盖层交互验收

- `--teaching --verify-license-notices` 从合成设置的关于页实际打开许可窗口，逐一比对全部随包许可/声明的显示原文与文件，检查 owned 关系和窄窗口。禁用该夹具设置窗口自动更新请求；不加载用户设置，生成的图片只有公开许可信息。可加 `--english` 检查英文布局。

- `--teaching --verify-answer-menus` 只打开合成历史/最新回复的复制菜单，检查共享外观、选中/未选中状态、完整历史不截断、最新流式尾句与 Emoji 复制、菜单开启时对话条保留。检查实际渲染阴影在面板外存在且四周最外像素透明；PNG 与结果仅保存 `.codex-build`。剪贴板原对象仅在内存中保存，结束恢复，不读取用户历史、不发送请求、不运行默认滚动演示。

- `--teaching --verify-thinking-glow` 仅回放合成呼吸光效，验证无回答时可见、输入焦点/光标保持、非命中层、颜色变更、旧取消/旧完成不影响新请求，以及取消/完成/禁用/关窗释放动画。设置页验证 RGB 接受/取消、草稿隔离、预览开关与 600 DIP 窄窗口；不读取真实设置、不发送 AI 请求、不启动默认滚动演示。同时断言光效抵达包含任务栏的完整显示器底边、底部实际渲染像素变化，以及对话条仍避开任务栏。输出仅为合成界面和断言记录。

- `--teaching --verify-video-pin` 专门验证真实区域录屏后的贴视频：12 次原件/带手写与动态时间轴标注的贴出、双播放器并存、播放暂停、缩放、切换置顶、关闭和强制测试 GC；最后关闭覆盖层，断言贴视频仍持续呈现帧，源 MP4 哈希不变。GC 只用于合成夹具暴露原生资源回收竞态，严禁移入产品。运行开始先使旧报告失效，阶段报告有界记录并在完成后输出结果；失败也关闭所有测试贴视频。此模式不读取用户设置、不调用 AI、不运行默认滚动演示。
- `--video-background-only` 的合成背景必须保持 Topmost，防止安装版主窗口隐藏后录到原先前台应用。安装版播放验收必须实际采样到红/蓝/绿变化，不能只看后台合成计时文本或窗口存活。
- 2026-09-09 `a0f7c2d` 修复验证：原始实现两次在带标注贴视频后 GC 崩溃，异常码/地址均与安装版 v0.3.2 一致；加入 Win2D 设备锁后两轮共 24 次通过。Release 全量 928 通过、1 项现场音频测试按开关跳过，根解决方案构建无警告。本机正式安装目录校验 341 文件一致，实际 PID 6104 加载 `0.3.2+a0f7c2dd3a1da2d45d6e8a0d1d04652127e8ce8e`；在该进程完成约 9 秒录屏、停止后输入焦点、矩形标注和贴视频，关闭覆盖层后连续采样 14 秒得到红/蓝/绿三色且无新原生崩溃。测试窗口已关闭。此记录不代表发布了新的 GitHub 发行版。

- `--teaching --verify-prompt-reveal-focus` 专门验证对话条弹出焦点：首次、收纳后重现、Visibility 隐藏后恢复、重复恢复、保留草稿/光标、已显示回答的选择、隐藏/关闭时撤销迟到焦点及离线不可见时不聚焦。只运行这个焦点夹具，不启动默认滚动演示；合成界面有验收标识，结束后自动关闭。最后关闭窗口的测试要保持 `ShutdownMode.OnExplicitShutdown`，避免在断言及写报告前提前退出 Dispatcher。

- 视频问题使用 `--teaching --verify-video-workflow --live-provider`（明确的真实 MiniMax 合成内容请求），走实际录制、两次变色、停止/暂停焦点、原位发送、批注时间及源哈希链路；不得启动默认滚动演示冒充视频验收。`--teaching --video-background-only` 只提供合成色块背景，供安装版 GUI 录制验证；不得上传背景之外的屏幕。

- 所有测试窗口必须明确显示验收标识，不能让用户把夹具误认为正式软件；运行可见验收前说明会短暂出现测试画面，结束后关闭全部夹具窗口。
- 正式覆盖层已移除教学状态标识；验收标签必须由夹具 MarkReplayWindow 自行创建，不能为测试向产品 XAML 加回标签。夹具必须显式指定 TeachingMode，避免产品默认开启影响普通防捕获验收。
- `--teaching` 创建共享可见的覆盖层；自 2026-09-08 共存改动起，它不再禁用录屏和长截图。工具条灰色也可能来自正在进行的 OCR/翻译，排查时须区分整个 Toolbar 的禁用与两个按钮独立禁用。
- 独立夹具通过只能证明对应夹具配置可用，不能证明正式实例已经修复。正式窗口仍置灰时，应检查正式进程的 IsTeachingMode、请求状态和禁用来源；2026-09-08 的实际原因是宿主设置开启教学模式，命令环境看到的是同路径隔离副本，不能再将其归因于用户误认测试窗口。
- `--verify-capture-tools` 默认使用正常防捕获，可加 `--teaching` 验收共享与采集共存。只使用自有合成背景，不读取用户配置、不上传画面，关闭电脑声音和麦克风。检查长截图启动/取消恢复、真实 RecordingReady、停止和 MP4 首中末帧像素；教学分支额外验证共享期间实际孔洞、滚动追加、F8 倒计时取消和全屏录屏/长截图完成。报告不代表会议远端客户端或录屏音频验收。
- UI 观察与能生成媒体的验收必须分开；不得为让按钮可用而绕过正式覆盖层防捕获。等待录制器须使用真实 RecordingReady 事件及有界超时。
- 可见验收必须正常启动并等待退出（PowerShell 可将 EXE 输出接到 Out-Null），不能使用隐藏窗口启动参数隐藏首个合成背景窗。2026-09-08 隐藏启动曾使绿色背景校验失败，正常启动后通过；这是夹具启动条件，不得据此删除产品的干净背景校验。
