# 覆盖层交互验收

- 所有测试窗口必须明确显示“自动化验收窗口”，不能让用户把教学模式夹具中的灰色录屏/长截图按钮误认为正式软件设置；运行可见验收前说明会短暂出现测试画面，结束后关闭全部夹具窗口。
- `--teaching` 仅用于界面观察；它真实禁用录屏和长截图，不能据此判断正常模式下两个入口不可用。普通工具条灰色也可能来自正在进行的 OCR/翻译，排查时须区分整个 Toolbar 的禁用与两个按钮独立禁用。
- `--verify-capture-tools` 使用正常防捕获和自有合成背景，不能与教学模式组合，不读取用户配置、不上传画面，测试关闭电脑声音和麦克风。当前验收范围是长截图启动/取消恢复，以及录屏倒计时、真实 RecordingReady、停止和生成视频；不能把入口验证报告为滚动拼接质量或录屏音频验收。
- UI 观察与能生成媒体的验收必须分开；不得为让按钮可用而绕过正式覆盖层防捕获。等待录制器须使用真实 RecordingReady 事件及有界超时。
