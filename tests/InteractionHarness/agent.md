# 覆盖层交互验收

- 所有测试窗口必须明确显示验收标识，不能让用户把夹具误认为正式软件；运行可见验收前说明会短暂出现测试画面，结束后关闭全部夹具窗口。
- `--teaching` 创建共享可见的覆盖层；自 2026-09-08 共存改动起，它不再禁用录屏和长截图。工具条灰色也可能来自正在进行的 OCR/翻译，排查时须区分整个 Toolbar 的禁用与两个按钮独立禁用。
- 独立夹具通过只能证明对应夹具配置可用，不能证明正式实例已经修复。正式窗口仍置灰时，应检查正式进程的 IsTeachingMode、请求状态和禁用来源；2026-09-08 的实际原因是宿主设置开启教学模式，命令环境看到的是同路径隔离副本，不能再将其归因于用户误认测试窗口。
- `--verify-capture-tools` 默认使用正常防捕获，可加 `--teaching` 验收共享与采集共存。只使用自有合成背景，不读取用户配置、不上传画面，关闭电脑声音和麦克风。检查长截图启动/取消恢复、真实 RecordingReady、停止和 MP4 首中末帧像素；教学分支额外验证共享期间实际孔洞、滚动追加、F8 倒计时取消和全屏录屏/长截图完成。报告不代表会议远端客户端或录屏音频验收。
- UI 观察与能生成媒体的验收必须分开；不得为让按钮可用而绕过正式覆盖层防捕获。等待录制器须使用真实 RecordingReady 事件及有界超时。
- 可见验收必须正常启动并等待退出（PowerShell 可将 EXE 输出接到 Out-Null），不能使用隐藏窗口启动参数隐藏首个合成背景窗。2026-09-08 隐藏启动曾使绿色背景校验失败，正常启动后通过；这是夹具启动条件，不得据此删除产品的干净背景校验。
