# MewuAI 1.0.7

- 新增默认启用的原生插件 **Hooks · 事件触发器**，设置侧栏独立入口，五类触发规则分页面管理。
- 支持 Cron 定时、提示词关键词/正则、AI 最终回复、全局快捷键、生命周期与自定义事件。
- 动作支持提示词注入、发送消息、MCP、命令、应用与网站、键鼠操作、JavaScript 计划及 Mewu 操作协议。
- 截图快捷键与「截图与录屏」共用原设置；可在 Hooks 中删除，不创建第二份快捷键配置。
- 规则支持独立开关、条件、冷却、超时、取消和运行记录；停用插件会撤掉入口并停止其自动化。
- 规则和运行账本随数据目录迁移，重启后不重放结果未确认的操作。

详见 [Hooks 使用文档](./hooks.md)。macOS 输入遵循辅助功能权限，Wayland 全局快捷键和输入使用系统 Portal 授权。无需 Agent Key 即可配置本地自动化；调用模型或外部 MCP 的动作仍需要对应连接。
