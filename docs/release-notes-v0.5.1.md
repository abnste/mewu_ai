# 喵呜AI 0.5.1 / MewuAI 0.5.1

- 修复历史对话、流式回答和原位批注中的 LaTeX 公式显示，覆盖二项式系数、常见转义和长公式排版；复制时仍保留可编辑的原始公式。
- 改善附件分析期间的状态反馈：截图会明确显示“AI 标注中”，成功、失败、取消和最小化状态会正确收尾，不再出现长时间整理但没有标注的假完成状态。
- 更新对话条和最小化悬浮窗的拖动、恢复和思考状态交互，保留原有视觉样式与任务栏范围内的拖动能力。
- 更新 README 中的双语功能演示图：试卷批注、Understand code 和 Draw and annotate 均使用最新示例，图片随源码仓库发布。

下载：[安装版 EXE](https://github.com/abnste/mewu_ai/releases/download/v0.5.1/MewuAI-Setup-0.5.1-win-x64.exe) 或 [便携版 ZIP](https://github.com/abnste/mewu_ai/releases/download/v0.5.1/MewuAI-Portable-0.5.1-win-x64.zip)。支持 Windows 10 2004 及以上 x64 系统，无需另装 .NET。SHA-256 可在 GitHub 下载资产详情中查看，不附带单独校验文件。

使用 v0.2.5 及更早版本时，请下载安装器手动升级。此前改动见[更新日志](https://github.com/abnste/mewu_ai/blob/v0.5.1/CHANGELOG.md)。

---

- Fix LaTeX rendering in historical conversations, streamed answers and in-place annotations, including binomial coefficients, common escaping and long-formula layout. Copying still preserves editable source formulas.
- Improve attachment-analysis status feedback: screenshots now show “AI annotating”, and success, failure, cancellation and minimized states finish cleanly instead of appearing to wait forever without annotations.
- Update composer and minimized-widget dragging, restoration and thinking-state interactions while preserving the existing visual style and taskbar-area reach.
- Refresh the bilingual README demos for paper annotations, Understand code and Draw and annotate with the latest examples, shipped in the source repository.

Downloads: [installer EXE](https://github.com/abnste/mewu_ai/releases/download/v0.5.1/MewuAI-Setup-0.5.1-win-x64.exe) or [portable ZIP](https://github.com/abnste/mewu_ai/releases/download/v0.5.1/MewuAI-Portable-0.5.1-win-x64.zip). Requires Windows 10 2004 or later, x64; no separate .NET installation is needed. SHA-256 digests are available in GitHub asset details; no separate checksum file is included.

If you use v0.2.5 or earlier, download the installer to upgrade manually. See the [changelog](https://github.com/abnste/mewu_ai/blob/v0.5.1/CHANGELOG.md) for earlier changes.
