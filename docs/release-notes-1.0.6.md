# MewuAI 1.0.6

- 支持通用插件来源迁移。在安装审核中确认原来源和新来源，保留插件 ID、配置、凭据、记忆、对象库及启停状态；同版本换源也可迁移。原安装包保留用于回滚，过期审核、并发变更、降级及包完整性错误仍会拒绝执行。
- 已安装插件不再重复出现在插件市场；已安装页面检查新版，有更新时显示“更新”，同版本来源调整显示“迁移来源”。
- 插件分类全部展开为文字标签，点击筛选，不再使用下拉框。
- “关于”固定在设置侧栏底部。打开设置自动检查软件更新，有更新时在按钮右侧显示“检测到新版本”；与关于页共用更新状态。

软件继续通过 GitHub Release 更新，插件由各自独立仓库发行。
