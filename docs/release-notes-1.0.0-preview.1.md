# 喵呜AI / MewuAI 1.0.0-preview.1

## 简体中文

1.0 重制版首个 Windows x64 预览版。

- 延续快捷截图、对话条、多会话与冻结会话，加入电子黑板。绘制、录屏及原位标注保留在截图空间中。
- 提供 Agent 灵魂设定、长期记忆、MCP 和 GitHub 插件安装与管理。
- 支持 Markdown、公式与思考收纳，修复 MiniMax 思考内容混入回答的问题；内置更新支持后续预览版及正式版。

旧版 API 连接支持一次导入；旧版会话历史暂不迁移。0.7.x 正式版不会自动切换到此预览版。

## English

The first Windows x64 preview of the 1.0 remake.

- Keep quick capture, the conversation bar, multiple conversations and freeze/resume. Add a whiteboard with drawing, recording and in-place annotations in the capture space.
- Add agent identity settings, persistent memory, MCP and GitHub plugin installation and management.
- Support Markdown, math and collapsible reasoning. Fix MiniMax reasoning leaking into answers, and include updates to future previews and stable releases.

Legacy API connections can be imported once; legacy conversation history is not migrated yet. Stable 0.7.x installations will not automatically switch to this preview.
