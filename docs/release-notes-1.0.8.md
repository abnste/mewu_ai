# MewuAI 1.0.8

- 截图快捷键统一为普通 Hooks 规则：可改名、换按键、编辑动作、停用和删除，不再使用专用卡片或系统截图开关。
- 升级时一次性导入旧快捷键，保留原设置；删除后重启不会重新添加。「截图与录屏」链接到同一条规则。
- Hooks 标题直接改名，匹配选项同排显示，高级选项使用统一表单样式；移除手动测试区和重复校验按钮。
- Mewu 动作从统一操作协议选择，截图等无参数动作无需填写 JSON。
- 绘制工具条优先放在选区外；全屏等空间不足时靠边放置，正在标注的笔迹接近时自动避让。

[Hooks 使用文档](https://github.com/abnste/mewu_ai/blob/master/docs/hooks.md)
