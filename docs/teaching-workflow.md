# 试卷、作业与知识讲解

教学批改不再有单独入口、侧栏或批改窗口。截图覆盖层的原有对话条就是唯一入口：框选一个或多个区域后，用自然语言直接描述要做的事，例如：

- “帮我批改这张试卷，逐题说明对错和错因。”
- “第 3、4 题怎么做？把步骤讲清楚。”
- “把每题答案填到对应空白处，并在旁边简短解释。”
- “这段 Scratch / Python 代码哪里错了？给出修正版。”
- “比较这两份作答，找共同错误并出几道练习题。”

语文、数学、英语、理化生、历史地理、图形化编程、Python、技术材料和其他知识都使用同一条对话流程。应用会保留原图，在回答区域显示解释；只有用户明确要求定位、批改或填答时，才在可见作答附近添加简短原位批注。完整说明仍留在对话条，用户可以按需移动对话条。

数学和理工公式使用可复制的 LaTeX：行内公式用 `$...$`，独立公式用 `$$...$$`。常见分数、上下标、根式和多步推导会在回答中排版，复制时保留原始公式文本，便于粘贴到 Word 公式编辑器。代码保持缩进和语言标记，修正版使用代码块展示。

当图片缺少题干、字迹无法辨认、答案位置被裁掉或评分依据不足时，回答会标为待核并说明需要补充的内容，不会猜读或伪造分数。多张作答会按附件标签和题号分别核对，避免把同一学生的多页误算成多人。

截图、上传、长截图和录屏都可以继续作为同一条对话的引用。没有视觉附件时，输入保持普通文字对话，不会隐式上传屏幕内容。
