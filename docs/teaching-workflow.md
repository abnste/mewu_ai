# 试卷与作业使用说明

在截图覆盖层的底部对话条点击纸张图标“试卷与作业”。所有页面、批改和对话仍在同一个覆盖层；这不是独立聊天窗口。

1. **收集页面**：填写作答代号（例如 A、B）和起始页码。可以“导入 PDF / 图片”，PDF 页码支持 `3,5-7`，留空取前 16 页；也可先框选多个区域，再点“收集截图”。同一学生的多页使用相同代号，不同学生使用不同代号。
2. **跨页截图**：点“继续截图”关闭覆盖层，翻到下一页，再用原截图快捷键唤醒并收集。旧页面保存独立像素，不随桌面变化；应用退出后会清空。用页面旁的“改代号/页码”应用顶部新填写的身份。重复页会被拦截。
3. **批改**：需要评分时先粘贴明确的评分细则；不填写则只判对错，不编造总分。勾选 1–4 页，点击“批改勾选页”。每页有初稿和复核两轮；格式异常至多重试一次该轮，完成页立即保留。停止或退出不会接收迟到结果。
4. **核对**：点击页面标签查看原卷，向下滚动面板逐题核对实际识读、正确答案、批改说明、判定、知识点和分值，再点“确认这道题”。计算过程保留分行，编辑框支持回车和自动折行；改判时可一起修正说明，导出会保留这些换行和说明。模型分歧、识读困难或缺少信息保留为待核；即使两轮一致，也不会自动替老师确认。框错位置时点“重新框出作答位置”，在原卷拖出新框。
5. **共性与练习**：至少确认两份不同作答中的共同错题，使用一致的知识点名称，再点“共性分析与出题”。统计只引用老师已确认的错误，不把同一学生的不同页面当成多人；空白和待核不计入共同错误。题目与答案可编辑，编辑后须重新确认。
6. **导出**：确认练习和答案后导出教学 ZIP。`annotated/` 是标注页，`review.csv` 包含逐题内容与确认状态，`questions.html` 和 `answers.html` 分开保存，可用浏览器打印。原 PDF/图片不被修改。没有生成练习时，只导出标注页和逐题表。

上限：每次应用会话中的作业集合最多 16 页、3200 万像素；本地文件最大 50 MB，图片源像素最多 4000 万，导入后最长边最多 1600 像素。每页最多 24 个题目/小问；密集整卷应选择更小区域，以免小字无法辨认。PDF 导入有独立超时和进程边界，无新第三方 PDF 依赖。
