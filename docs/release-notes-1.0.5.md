# MewuAI 1.0.5

- 区域操作插件支持 Windows、macOS 和 GNOME Wayland：从对话条发起，在授权选区内点击、输入，并根据新的截图反馈继续。macOS 需要辅助功能与录屏权限；本轮 Linux 区域输入适配范围为 GNOME 50、Wayland、x64，需要 Mewu Desktop Witness 和系统 Portal 当次授权。
- Hindsight 改为独立插件。设置中可选择服务器已有的记忆库，保存后的 Key 使用真实密码框回填；停用插件会撤去其设置入口和记忆能力，原档案保留。
- 截图选区按 Enter 确认复制并退出，保留未发送的对话草稿；工具包支持首次拖入直接收藏。
- 修复置顶便笺的 Esc 行为与置顶状态显示，以及 macOS 置顶视频循环重播时的白帧。
- 改进录屏倒计时、裁切定位、播完后的再次播放和工具条布局；翻译显示真实批次进度。
- 修复 Firefox 辅助功能属性读取、Wayland 指针异步确认及静态桌面新帧获取。区域插件可重新观察异步页面，不重复发送已执行的输入。
- CLI 支持按录制 ID 查询任务结束状态与原生错误，避免把“当前无录制”误认为文件已经保存。
- 模型插件的默认单次执行总上限延长至 5 分钟，容纳系统授权与多轮截图反馈；显式设置的较短预算、取消操作和资源限制继续生效。

安装包沿用 GitHub Release 自动更新，不新增更新频道、latest.json 或独立签名文件。
