# Hooks · 事件触发器

Hooks 是随 Mewu 安装、默认启用的原生插件。可在「插件 → 原生」停用；停用会撤掉 Hooks 的设置入口、定时器和自定义全局快捷键，并停止尚未完成的动作。规则及工作目录保留，重新启用后仍可使用。

在设置侧栏打开 **Hooks**，选择触发类型，添加一条规则并保存。点击行首名称直接改名，每条规则可单独开关、修改、删除及查看运行记录。保存时自动校验配置。

| 触发类型 | 匹配内容 |
| --- | --- |
| 定时触发 | 标准五段 Cron，或含秒的六段 Cron；支持 IANA 时区和 `local` |
| 提示词触发 | 用户首次提交或继续对话时的原始提示词；包含、完全匹配或正则表达式 |
| AI 回复触发 | 一次回复完成后的最终正文；不会对每个流式片段重复执行 |
| 快捷键触发 | 在其他应用获得焦点时也有效的全局快捷键 |
| 事件触发 | 生命周期、插件事件或自定义事件；可添加 JavaScript 条件 |

例如，匹配内容设为 `？`、方式设为「包含」，添加「注入提示词」动作，即可在发送含中文问号的问题时添加指令。英文 `?` 是另一个字符；只有选择正则表达式时才按正则语法解释。注入内容仅作用于当次请求，不改写用户原文或 Agent 的灵魂设定。

## 动作

支持注入提示词、发送提示词、调用已配置 MCP 工具、执行 CMD / PowerShell / Shell、运行本地程序、打开应用或网站、键鼠操作、JavaScript、触发自定义事件、Mewu 操作和等待。动作按排列顺序执行。「失败后停止」控制后续动作是否继续。

程序与应用使用本机绝对路径。未指定命令工作目录时，使用数据目录下该规则自己的工作目录。命令以当前用户身份运行，事件 JSON 从标准输入传入；不会将提示词拼接成命令。命令输出不写入运行记录。CMD 仅适用于 Windows；Shell 适用于 macOS / Linux；PowerShell 需要相应系统环境已安装。

键盘动作中的字母表示按键名称，`Control+A` 与 `Control+a` 相同；需要 Shift 时明确写成 `Control+Shift+A`。输入带大小写的正文使用「文字」步骤，不会改变正文字符。

提示词规则在提交前同步执行，可注入指令、调用 MCP、运行命令或执行键鼠动作。再次发送消息或操作 Mewu 界面应使用其他触发类型；需要从关键词串联界面操作时，先发出自定义事件，再由对应事件规则执行，避免等待当前提交所在的同一界面队列。

MCP 动作复用现有服务配置、实际工具清单和参数校验；已停用、删除或更改的服务不能借旧规则继续调用。

Mewu 操作使用与界面及 CLI 相同的操作协议，例如 `capture.open`、`blackboard.create`、`scene.newConversation`。操作名称和参数见 `mewu schema`。「发送提示词」负责新请求的来源追踪，不使用普通 Mewu 动作绕过对话递归保护。

## 条件与 JavaScript

需要额外判断时，在「高级选项 → 条件（JavaScript）」填写函数体，返回 `true` 执行，返回 `false` 跳过。例如：

```js
return event.platform === 'windows' && event.text.includes('？');
```

`event` 包含 `id`、`name`、`timestamp`、`platform`、`sceneId`、`runId`、`text`、`payload` 及自动化来源。平台值为 `windows`、`macos`、`linux`。

JavaScript 动作返回一个计划；宿主校验后执行：

```js
return {
  actions: [{ kind: 'openUrl', url: 'https://example.com/' }]
};
```

提示词触发还可返回 `{ prompt: '附加指令' }`。JavaScript 使用独立、纯运算环境，没有文件、网络或进程对象；需要这些能力时返回相应动作，或使用命令动作。每次运算限时 100 ms、内存 16 MiB，返回内容最多 64 KiB。保存时只校验语法，不运行函数体。

## 生命周期

`app.started`、`app.beforeQuit`、`capture.opened`、`scene.created`、`scene.activated`、`scene.closed`、`agent.started`、`agent.replyCompleted`、`agent.failed`、`tool.completed`、`tool.failed`、`plugin.changed`、`plugin.event`。

`app.started` 在存储和界面操作队列就绪后触发一次；重载界面不会重复触发。退出前规则共享三秒上限，避免命令或系统授权窗口阻止退出。自定义事件名称使用 `custom.` 前缀，由「触发事件」动作发出。事件内容始终作为数据处理。

已有 `events.emit` 权限的社区插件可通过原 SDK 发出事件。Hooks 接收为 `plugin.event`，`payload` 中包含 `pluginId`、`pluginRevision`、`name` 和 `data`；可用条件筛选指定插件或事件。插件不能伪装成应用生命周期或 AI 回复事件。逐段文字与思考流不转成 Hooks 事件。

## 快捷键与系统授权

原截图快捷键和 Windows 的 Win+Shift+S 在升级时各导入一次普通规则：触发器是全局快捷键，动作是「Mewu 操作 → 唤起截图」。可以改名、改按键、替换或增加动作、停用和删除，没有专用开关或不可编辑的默认项。删除后重启不会恢复；「截图与录屏」列出仍会唤起截图的规则，点击即可进入同一编辑器，全部删除后显示未设置。停用 Hooks 会撤销包括这些规则在内的快捷键；托盘截图等核心入口继续可用。

Wayland 的全局快捷键统一使用 GlobalShortcuts Portal，由系统确认并分配实际按键；界面显示系统返回的按键，而非把首选按键误报为已生效。所有规则只保存在 `hooks.db`；旧设置仅作为一次性导入来源，之后不再参与执行或覆盖规则。macOS 键鼠操作需要系统辅助功能权限；Wayland 键鼠操作使用独立 RemoteDesktop 授权会话，遵守系统撤权及所选屏幕边界，不借用区域操作或截图授权。

## 执行与保存

每条规则有独立冷却、超时和停止状态；同一条规则不重叠运行。定时任务不积累补跑：休眠恢复时最多合并触发一次，软件重启或重新启用后从下一时点开始。长按或重复快捷键不累积执行队列。

发送提示词及自定义事件携带自动化来源：已执行的规则不会在同一自动链中重入，链深最多八层。并列匹配的多条规则不消耗链深。键鼠模拟不会直接重新触发 Hooks 自己的全局快捷键。

规则和最近运行记录保存在数据目录的 `hooks.db`。修改采用版本检查，防止覆盖另一个编辑器的新修改。运行记录不保存提示词正文、Key 或命令输出；最近最多保留 500 条终态记录。重启后上次未确认完成的执行记为中断，不重放。系统操作已经开始但结果未知时，也不会自动重试。
