# MewuAI 0.0.2 / 喵呜AI 0.0.2

A focused upgrade to the in-place capture, annotation, and multimodal workflow. / 本次更新集中完善原位截图、标注与多模态工作流。

## Highlights / 主要更新

- Smart window selection, directional handle snapping, scrolling capture, and live RGB/coordinate readout. / 智能窗口框选、方向句柄吸附、长截图与实时 RGB/坐标显示。
- Rectangle mosaic plus richer hand-drawn and AI annotations, with draggable callouts and unified image/video annotation protocol. / 新增矩形马赛克，增强手工与 AI 标注，气泡可拖动，并统一图片/视频标注协议。
- Exact `@RegionN`, `@ImageN`, and `@VideoN` references with corrected multi-attachment mapping. / 支持精确的区域、图片、视频引用并修复多附件映射。
- Rotatable pinned images preserve their current orientation when copied or saved; double-click unpins. / 贴图支持旋转并按当前状态复制或保存，双击取消置顶。
- Backend-aware AI UI, improved Hermes discovery, provider-backed translation, and more actionable desktop speech recognition errors. / AI 入口按实际后端显隐，改进 Hermes 发现、Provider 翻译与桌面语音识别提示。
- Expanded compatible-provider model discovery and capability detection without hard-coding a promotional default. / 扩展兼容 Provider 的模型发现与能力识别，宣传材料不再写死默认模型。
- Translation is preserved in pin/copy/export flows, while offline capture, OCR, annotation, and recording remain available without AI. / 译文可随贴图、复制和导出保存；离线截图、OCR、标注与录屏始终可用。

## Packages / 下载包

- `MewuAI-Setup-0.0.2-win-x64.exe` — per-user installer. / 当前用户安装版。
- `MewuAI-Portable-0.0.2-win-x64.zip` — self-contained portable build. / 自包含免安装版。

## Requirements / 系统要求

Windows 10 2004 (build 19041) or newer, x64. Windows N/KN editions require the Microsoft Media Feature Pack for H.264 recording and preview.

Windows 10 2004（build 19041）或更高版本，x64。Windows N/KN 版本需要 Microsoft Media Feature Pack 才能录制和预览 H.264。

> The binaries are not Authenticode-signed. Verify the attached SHA-256 checksums. / 安装包尚未进行 Authenticode 签名，请核对附件中的 SHA-256 校验值。
