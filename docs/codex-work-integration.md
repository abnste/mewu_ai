# 本机 ChatGPT Work / Codex 接入

喵呜AI 通过官方 `codex app-server` 的 stdio JSON-RPC 接口接入本机 Codex，沿用官方客户端管理的 ChatGPT 登录。喵呜AI 不读取或复制 `auth.json`、Cookie、访问令牌，不调用 ChatGPT 私有聊天接口，也不提供“免费 Chat”入口。

官方资料：

- [App Server](https://learn.chatgpt.com/docs/app-server)：第三方产品的认证、模型、会话和流式事件接口。
- [认证](https://learn.chatgpt.com/docs/auth)：ChatGPT 登录与 API Key 是不同认证路径。
- [用量](https://learn.chatgpt.com/docs/pricing)：ChatGPT Work 和 Codex 共用用量；额度和积分按账号套餐计入，不代表每条工作消息都直接扣额外购买积分。
- [配置](https://learn.chatgpt.com/docs/config-file/config-reference)：会话权限、工具和历史设置。

## 使用

在官方 ChatGPT 桌面应用或 Codex CLI 登录后，打开喵呜AI「设置 → AI」的 Codex 配置页，选择模型、思考程度并保存；对话条上传按钮后的模型入口用于切换本轮渠道。页面检测本机登录与真实模型目录；检测不发送提示词或屏幕附件，也不购买积分或兑换额度重置。

顶部 API、Hermes、Codex 可以同时保留配置；覆盖层在存在多个可用渠道时提供本轮选择，切换会保留其他后端配置，历史按渠道隔离。远程 API 配置继续保留，原位翻译仍沿用其原有路由。Codex 失效时不会把问题偷偷发往 API 或 Hermes。

## 数据与生命周期

仅在用户明确发送后创建临时会话并交接附件。文字和截图通过官方文字、`localImage` 输入处理；历史上下文沿用项目的 20 条 / 24,000 字符上限，每轮创建 ephemeral 会话，不把无限历史留给后台自动累积。

视频复制到本轮独立工作目录，以带 `regionIndex` 的本机文件路径交给 Codex。Codex 可使用已有的本机命令和看图工具自行检查视频，派生帧只允许写入本轮目录；不伪造官方原生视频输入类型、不自动安装解码软件。源视频由租约保活，复制和临时文件使用独立租约。不同电脑的可用解码工具会影响视频识别，模型无法实际读取时必须说明，不能编造内容。

不加载其他应用连接、MCP 工具、插件、Hooks、记忆或项目 AGENTS 内容，不继承用户的快速收费档；本轮使用标准速度。文字/图片会话使用只读权限，视频会话使用独立工作目录写权限并关闭工具网络。超出本轮权限的工具请求不自动批准。用户取消时先有界请求 `turn/interrupt`，再停止本轮后台进程；单轮最长 10 分钟。

响应必须匹配本轮 thread / turn，收到成功终态且存在非空最终回答才返回成功。仅有思考、commentary、自然 EOF、失败或中断均不得当作完成。结构化视觉批注继续使用喵呜AI 既有解析、区域绑定和视频时间轴校验。原始后台输出不写日志，错误只呈现固定类别与接口错误码。

## 兼容记录

2026-09-06 本机 Codex CLI `0.153.4`，官方登录与 6 个模型的目录检测通过；文字挑战 `MEWU_OK`、合成红色图片识别及图片缓冲清零通过。4 秒合成视频由 Codex 自行调用本机工具后正确回答 `red blue`，对应前 2 秒红色、后 2 秒蓝色，源文件 SHA-256 保持不变。上述最小推理挑战使用目录中真实可用的 `gpt-5.4-mini` / `low`，不代表所有模型或其他电脑的解码环境都已验证。

该版本协议 Schema 仍列出 `untrusted`，但实际运行已拒绝此权限值，应使用 `on-request`。App Server 的会话 `config` 使用点分路径，不能把 CLI TOML 的引号语法直接嵌入键名；含复杂分隔符的 MCP 名称安全拒绝，不冒险留下未隔离的连接。进程启动时的工具开关优先级高，视频工具必须在启动时启用，不能只在 `thread/start` 时覆盖。

上述验证记录对应最初本地适配阶段，当时未发布标签或替换 v0.2.6 安装包。该接入纳入 0.3.0 发布，完整变更见 `release-notes-v0.3.0.md`。
