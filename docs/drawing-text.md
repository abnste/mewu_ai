# 绘制文字

截图、黑板和视频文字共用原位编辑器与字面文档。双击文字进入编辑；选中其中一段后，颜色、加粗、斜体、下划线和删除线作用于这段文字。没有选区时，格式作用于接下来输入的文字。选择工具选中整个对象后，样式操作作用于整个文本框。

Enter 换行，Ctrl/Command + Enter 确认。编辑期间的 Ctrl/Command + Z 使用文字编辑历史；确认后使用原绘制文档的撤销与重做。中文输入法组合输入交给 ProseMirror，宿主不把组合中的 Enter 当作截图确认。

黑板编辑时，再次点击当前文字工具只展开或收起参数，保留文字选区；Esc 关闭参数后回到文字编辑。选择其他工具或明确确认时，才沿原事务提交流程完成编辑。

选择工具提供八个缩放手柄，顺序为左上、上、右上、右、右下、下、左下、左。调整文本框宽度重新换行，不改变字号；文本内容不会因为框变小而截断。字号仍是整个文本对象的属性。

## 文档契约

`Drawing.text` 保留完整字面原文。可选 `textRuns` 是按顺序排列的 `{ text, color?, textStyle? }` 片段，拼接必须与原文完全相等，不能携带 HTML、CSS、字体地址或脚本。片段省略颜色或样式时继承对象属性；显式空 `textStyle` 清除该片段的效果。

所有片段共用原有文本长度预算。旧文档不添加无意义的片段字段，旧视频布局的序列化与渲染身份保持可读。含片段的视频文字使用新的渲染样式身份；生成的 PNG、文档哈希和恢复时的验证均包含这些片段。

编辑、确认时的可见字形均由同一份 SVG 绘制；原位编辑层负责光标、选择与输入，不重复显示第二份文字。这样斜体、装饰线和自动换行不会在确认时改用另一套字形。原生截图导出和视频文字栅格同样读取这些字面片段。

存储版本升级到 14，迁移保留原文和绘制历史，并推进一次 CAS 修订以阻止旧写入者覆盖新格式。降级运行需恢复升级前的数据库备份。

使用 [ProseMirror](https://prosemirror.net/docs/guide/) 处理文字选择、组合输入、段落和编辑历史；截图、对象移动、绘制事务、权限与持久化仍归原宿主接口管理。
