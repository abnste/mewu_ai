# 喵呜AI 0.5.7 / MewuAI 0.5.7

- 录制期间，控制条之外的鼠标移动、点击和滚轮输入会转发到下层应用；控制条仍可暂停、继续和停止录制。
- 录屏控制条、截图工具条和标注工具条的阴影改为独立图层，避免阴影被裁切或影响文字清晰度。
- 录屏倒计时、原位录制、全屏录制和结束后的窗口交互恢复继续由 Release 录屏回放覆盖。

下载：[安装版 EXE](https://github.com/abnste/mewu_ai/releases/download/v0.5.7/MewuAI-Setup-0.5.7-win-x64.exe) 或 [便携版 ZIP](https://github.com/abnste/mewu_ai/releases/download/v0.5.7/MewuAI-Portable-0.5.7-win-x64.zip)。

---

- While recording, mouse movement, clicks, and wheel input outside the control bar are forwarded to the application underneath. The recording bar remains available for pause, resume, and stop.
- Shadows for the recording, capture, and annotation toolbars use separate visual layers so shadows are not clipped and text remains sharp.
- Release recording replay continues to cover the countdown, in-place recording, full-screen recording, and interaction restoration after recording ends.
