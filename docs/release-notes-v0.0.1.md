# MewuAI 0.0.1 / 喵呜AI 0.0.1

The first public Windows x64 release of MewuAI. / 喵呜AI 首个公开 Windows x64 版本。

## Highlights / 主要功能

- Native multi-region capture and in-place annotation. / 原生多区域截图与原位标注。
- Offline PP-OCRv6 multilingual OCR and in-place translation. / 离线 PP-OCRv6 多语言 OCR 与原位翻译。
- Region MP4 recording, GIF export, video understanding, seek chips, and tracked timeline annotations. / 区域 MP4、GIF 导出、视频理解、时间跳转气泡与动态跟踪标注。
- MiniMax M3, OpenAI-compatible providers, and local Hermes Profile/Agent integration. / MiniMax M3、OpenAI-compatible Provider 与本机 Hermes Profile/Agent 接入。
- Streaming Markdown, reasoning, color emoji, voice input, and optional Hermes TTS. / 流式 Markdown、思考过程、彩色 emoji、语音输入与可选 Hermes TTS。
- DPAPI credentials, capture-protected windows, bounded history, scrubbed buffers, and sanitized logs. / DPAPI 凭据、窗口防捕获、有限历史、缓冲清零与脱敏日志。

## Packages / 下载包

- `MewuAI-Setup-0.0.1-win-x64.exe` — per-user installer with Start Menu shortcut and uninstaller. / 当前用户安装版，含开始菜单快捷方式与卸载器。
- `MewuAI-Portable-0.0.1-win-x64.zip` — self-contained portable build. / 自包含免安装版。

## Requirements / 系统要求

Windows 10 2004 (build 19041) or newer, x64. Windows N/KN editions require the Microsoft Media Feature Pack for H.264 recording and preview.

Windows 10 2004（build 19041）或更高版本，x64。Windows N/KN 版本需要 Microsoft Media Feature Pack 才能录制和预览 H.264。

> The binaries are not Authenticode-signed in this release. Verify the SHA-256 checksums attached to this release. / 本版本尚未进行 Authenticode 签名，请核对 Release 附带的 SHA-256 校验值。
