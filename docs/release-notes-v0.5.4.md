# 喵呜AI 0.5.4 / MewuAI 0.5.4

- 框选拖动预览复用冻结桌面截图，避免每次鼠标移动都重新创建裁剪位图，提升选区跟手性。
- 录屏改用更稳定的软件 H.264 编码路径，改善外部播放器中的帧时间和播放流畅度。
- 新增框选预览在 100% 与 175% DPI 下的像素一致性回归测试。

下载：[安装版 EXE](https://github.com/abnste/mewu_ai/releases/download/v0.5.4/MewuAI-Setup-0.5.4-win-x64.exe) 或 [便携版 ZIP](https://github.com/abnste/mewu_ai/releases/download/v0.5.4/MewuAI-Portable-0.5.4-win-x64.zip)。支持 Windows 10 2004 及以上 x64 系统，无需另装 .NET。SHA-256 可在 GitHub 下载资产详情中查看，不附带单独校验文件。

---

- Reuses the frozen desktop image during selection dragging instead of creating a new bitmap crop for every mouse move, making the selection follow the pointer more smoothly.
- Uses the more stable software H.264 encoding path to improve frame cadence and playback smoothness in external players.
- Adds pixel-consistency regression coverage for selection previews at 100% and 175% DPI.

Downloads: [installer EXE](https://github.com/abnste/mewu_ai/releases/download/v0.5.4/MewuAI-Setup-0.5.4-win-x64.exe) or [portable ZIP](https://github.com/abnste/mewu_ai/releases/download/v0.5.4/MewuAI-Portable-0.5.4-win-x64.zip). Requires Windows 10 2004 or later, x64; no separate .NET installation is needed. SHA-256 digests are available in GitHub asset details; no separate checksum file is included.
