本次更新修复 [Issue #2](https://github.com/abnste/mewu_ai/issues/2) 中的对话图片不显示和翻译文字重叠问题，并简化回复图片的外观。

### 对话图片

- AI 回复中的网页图片和内嵌图片可直接显示，随回答宽度缩放。
- Hermes 生成或发送的本地图片、MEDIA 引用及成功的图片工具结果可显示在回答中，重复引用只显示一次。
- 去掉图片容器的灰色占位底色和程序添加的“[图片：…]”标签；复制回复时仍保留图片说明及相邻文字、表情。
- 图片加载超时、无法读取或本地文件已失效时给出提示；新请求和取消操作正确切换图片，避免旧结果串入新回复。

### 原位翻译

- 修复长译文覆盖相邻文字、双栏内容互相重叠的问题。
- 根据原文行列位置分配显示空间，自动换行并调整字号；显示、文字选择和导出使用一致的布局。

### 下载与更新

- 提供 Windows x64 安装版 EXE 和便携 ZIP，包含运行环境及第三方许可证。
- 使用 GitHub 资产详情中的 SHA-256 digest 校验下载文件，不附带单独的 SHA256SUMS.txt。
- 可在设置中检查更新。v0.2.5 及更早版本请从发行页手动下载安装版升级。

This update fixes missing images in AI replies and overlapping in-place translations reported in [Issue #2](https://github.com/abnste/mewu_ai/issues/2), and simplifies how reply images look.

### Images in replies

- Web and embedded images in AI replies now display directly and resize to fit the reply area.
- Local images sent or generated by Hermes, MEDIA references, and successful image-tool results appear in the reply. Duplicate references are shown once.
- Removed the gray image backdrop and app-added image labels. Copying a reply still preserves image descriptions, surrounding text, and emoji.
- Timeouts, unreadable images, and missing local files show a useful message. Starting or cancelling a request keeps images associated with the correct reply.

### In-place translation

- Fixed long translations overlapping neighboring lines or crossing into adjacent columns.
- Translations wrap and adjust their font size within space allocated from the original text layout. Display, text selection, and export use the same placement.

### Download and update

- Windows x64 installer EXE and portable ZIP include required runtimes and third-party licenses.
- Verify downloads using the SHA-256 digest in each GitHub asset's details. No separate SHA256SUMS.txt is included.
- Check for updates in Settings. Users on v0.2.5 or earlier should download the installer manually from the release page.
