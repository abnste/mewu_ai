# 喵呜AI 0.6.1 / MewuAI 0.6.1

本版本基于 v0.6.0，主要整理 MCP 设置界面，并保留 v0.6.0 的全部功能。/ This release is based on v0.6.0. It reorganizes the MCP settings experience while retaining all v0.6.0 functionality.

## 更新内容 / Changes

- **MCP 设置分组。** MCP 服务按“邮箱”“消息与分享”“知识库与笔记”归类，每个服务以可展开列表项呈现，减少页面拥挤；QQ 邮箱、网易邮箱、钉钉、飞书、Obsidian 和 ima 的配置逻辑不变。/ **Grouped MCP settings.** Services are organized into Email, Messaging and sharing, and Knowledge and notes. Each service is an expandable list item to reduce visual clutter; the existing QQ Mail, NetEase Mail, DingTalk, Feishu, Obsidian and ima configuration flows are preserved.
- **发行准备同步。** 项目、安装器和发行校验统一使用 0.6.1。/ **Release preparation synchronization.** The project, installer and release checks consistently use version 0.6.1.
