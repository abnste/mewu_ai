# MewuAI 1.0.10

- 外部 Agent 接入原有对话条：在 Agent 菜单选择执行引擎，在模型菜单选择该客户端实际提供的模型。
- 修复 Codex 客户端升级后安装路径变化、旧默认模型失效及自定义模型服务的连接判断。
- 补齐 MiniMax Code 官方 Node CLI 和 macOS、Linux 常见安装目录的自动识别；手动指定的程序及参数保留。
- 客户端拒绝模型切换时保留原选择，登录、额度及服务错误给出明确提示，不自动重复提交任务。
- 修复切换执行引擎时菜单偶尔不收起的问题，避免迟到的模型列表覆盖当前会话。

外部 Agent 插件需单独更新至 0.1.6。仍需先在相应官方客户端完成登录；连接检测不代表所有模型均有使用权限。
