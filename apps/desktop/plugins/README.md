# Mewu 插件 API 1

当前格式支持模型连接模板、截图选区工作流、绘制工具集、本机文字识别、手动长截图、原位翻译、图片贴图、记忆服务适配器、语音输入、本地扫码和屏幕录制声明，兼容旧版原位标注贡献。插件是 UTF-8 JSON 文件，不载入脚本、二进制或第三方界面。通讯渠道、外部 Agent 运行时和第三方 OCR 引擎的独立运行接口尚未实现；现有 dsh 插件不能直接安装。

`official-table.json`、`official-ocr.json`、`official-scroll.json`、`official-translation.json`、`official-pin.json`、`official-memory-hindsight.json`、`official-voice.json` 和 `official-codes.json` 以及 18 个 `official-provider-*.json` 模型适配包是安装时提供的正式包。第一次启动自动安装并启用，后续启动保留停用、卸载和版本选择。移除插件不会删除文档中已有的标注、识别文字、长截图或译文，也不会关闭已生成的独立贴图窗口。视频已有裁剪范围仍按保存结果播放和导出。记忆插件安装后不自动联网，仍需用户配置服务并为 Agent 选择来源。

统一发送中的原位作答、图片标注和视频理解由应用核心提供，无需安装或启用标注插件。旧官方标注包清单已移至 [迁移清单](migrations/official-annotations-1.0.0.json)，只用于历史包兼容，不作为当前插件市场条目。

截图与视频绘制、屏幕录制、声源、裁剪和 GIF 导出由应用核心提供，随软件安装可用，插件管理不控制这些基础能力。旧绘制与录屏清单移至 `migrations/`，现有安装记录和文件保留，不再自动升级或归并，不作为市场条目。

## 开发与安装

复制 [示例](examples/selection-workflow/mewu-plugin.json)，修改标识、名称和提示词。在设置 → 插件 → 添加中选择本地 JSON，检查详情后安装。开发修改要增加 SemVer 版本号；同一版本不能替换为不同内容。当前包上限 64 KiB，最多 16 个贡献点。

放到自己的公开 GitHub 仓库根目录，文件名为 `mewu-plugin.json`，即可用仓库链接安装。也可使用 `https://github.com/OWNER/REPO/blob/REF/path/plugin.json`。安装前解析出完整提交，展示来源和 SHA-256；实际安装的是已展示的文件字节。预览十分钟后失效。检查更新读取同一仓库默认分支上的同一路径，比较版本后再次确认，不自动执行仓库构建脚本。

含斜杠的分支名请使用 GitHub 的完整提交链接。当前不支持私有仓库、认证令牌、npm、压缩包和 GitHub Release 资产。公开 GitHub API 有请求额度，失败不会覆盖已安装包。

## 贡献点

`agent.visual-annotations` 是兼容保留的贡献类型，只接受 `id`、`title` 和 `engine: "host.vector-v1"`。统一发送时，宿主根据本轮引用的截图或视频建立不可变坐标映射，以核心能力提供受限批注工具；由模型决定是否调用，直接文字回答也有效。该能力与 Agent 的长期记忆开关独立，不需要旧标注包，也不会因为安装或启用插件发起模型请求。

模型只能向本轮获准的选区追加宿主支持的可编辑图元，不能清空或替换用户手绘，也不能执行 SVG、HTML 或脚本。宿主核对源图、选区、可见图层和核心能力版本，将同选区的一批图元、撤销记录与工具回执一起保存。停用、卸载或更新旧标注插件不会撤销核心标注能力；已完成图元随文档保留，可继续编辑、复制、导出和撤销。清单不接受提示词、端点、模型、权限列表、自动执行或替换策略。模型没有返回合法批注时不会自动重试付费请求。

贡献点统一以 `kind` 区分类型。

`selection.recording` 包含 `id`、`title` 和 `engine: "windows.wgc-mf"`。这是兼容保留的第三方贡献类型，仍要求精确插件授权；核心录制通过独立的 `mewu.core.recording@1/record` 提供，停用或卸载旧录屏包不会阻止录制。录制、音频设备和文件输出仅在用户开始录制后启用。

`artifact.video-gif` 包含 `id`、`title` 和 `engine: "windows.media-editing-gif"`。核心 GIF 导出使用 `mewu.core.recording@1/gif`；第三方声明继续使用精确插件修订号。清单不接受脚本、命令、文件路径、远端地址、编解码器、帧率、循环设置、范围或自动导出字段。Windows 导出使用宿主固定的取帧、显示区域裁切、编码预算与文件校验流程。

`recording.audio` 包含 `id`、`title` 和 `engine: "windows.wasapi"`。核心声源使用 `mewu.core.recording@1/audio`；没有保存偏好时默认电脑声音，已保存的静音、麦克风或混合选择保留。声源只在设置 → 截图与录屏中选择，工具条不重复提供菜单。保存偏好不会打开设备，实际采集只在用户开始录屏时发生；系统或麦克风采集失败会明确报错。第三方声明仍受精确插件授权约束。

`artifact.video-trim` 包含 `id`、`title` 和 `engine: "windows.media-editing"`。屏幕录制包 `mewu.recording` 1.0.0 的贡献点 `trim`，仅授权宿主的视频范围编辑、撤销和重做；不接受脚本、命令、编解码器包、文件路径或自动导出。调整起止位置的一次手势只保存一次，原视频资产保持不变。停用或卸载后编辑入口消失，已提交范围仍能播放和保存；不会退回导出完整原片。用户明确保存时，Windows 本机媒体能力生成新片段，能力或格式不可用时报告失败。

`selection.codes` 包含 `id`、`title` 和 `engine: "rxing"`。官方 `mewu.codes` 1.0.0 的贡献点为 `recognize`，由宿主在稳定的活动选区自动进行本地识别，使用包含译层、马赛克与标注的可见合成图；不重新截屏、不调用模型或联网识别。支持 QR Code、Data Matrix、Aztec、PDF417、EAN-13、EAN-8、UPC-A、Code 128 和 Code 39。结果只保留在当前运行期，最多 12 个不同内容，每项最多 8 KiB、整份结果最多 64 KiB，超限整份失败而不截断。复制或打开必须由用户明确点击；只有显式 HTTP(S) 链接提供打开动作，不执行二维码中的命令、文件地址或 Wi-Fi 配置。插件不能指定脚本、端点、命令、格式列表或自动打开。源图、选区、可见图层、活动会话及插件授权变化会撤销旧结果的操作权限；停用和卸载取消识别。

`input.speech-to-text` 包含 `id`、`title` 和 `engine: "windows.sapi"`。官方 `mewu.voice` 1.0.0 的贡献点为 `dictation`，只调用宿主的 Windows SAPI 一次听写。安装或默认启用不会打开麦克风；用户在对话条明确开始后，识别结果只写入当前草稿，由用户自行发送。语言和默认输入设备由宿主与用户控制，不允许清单指定设备、音频路径、远程端点、命令、提示词或自动监听。识别器与语言需已安装；缺失时报告不可用，不自动下载模型或切换到云端。停用、卸载和版本变化撤销在途听写，已有草稿保留。它不提供连续通话、音频附件或录屏声音。

`memory.provider` 包含 `id`、`title` 和 `adapter: "hindsight"`。它选择宿主内置的 Hindsight HTTP 适配器，不允许清单携带服务地址、密钥、bank ID、脚本或模型提示。每个绑定的地址与独立凭据由用户在 Agent 设置中配置，宿主建立专用 bank；改变地址或密钥建立新绑定，旧数据和任务不迁往新目标。首版适配 Hindsight `0.10.3`，使用有来源的 world/experience 事实，尚不启用 observations/reflect。

默认记忆来源仍是本地。外接来源支持按问题检索、明确记录用户原文和手动记录；“同步之后完成的对话”默认关闭，不补传历史或附件。宿主保留原始证据与持久任务账本；受理、完成、本地排除和远端删除分开记录。远端取消或暂时查不到文档不构成彻底删除证明，已忘记的来源会持续被本地过滤。停用、卸载或版本变化阻止旧授权继续调用；已有本地证据仍可查看和导出。

`selection.pin` 只包含 `id` 和 `title`。官方 `mewu.pin` 1.0.0 的贡献点为 `pin`，由宿主将选区合成图显示为独立图片窗口。声明不能包含脚本、命令、HTML 或窗口 URL。停用、卸载及版本变化撤销新建入口和未完成的创建；已完成的贴图是独立图片，不随插件卸载销毁。

`selection.translation` 只包含 `id` 和 `title`。用户在选区执行后，本机 OCR 识别原图（保留马赛克，排除旧译文和其他标注），只将文字发送给当前所选连接。支持简体中文、英语、日语、韩语、德语、法语和西班牙语。完整结果以原位图层及选字框保存，屏幕与图片导出使用同一排版；不写聊天消息，不授予记忆或 MCP 工具，不自动重试请求。插件不能提供自定义提示、端点或脚本。关闭、取消、源图/绘制/连接变化及插件停用或删除会阻止在途结果写入；已保存译文随文档保留，后续绘制叠在译文之上，源图或选区几何变化使旧译文失效。

`selection.scroll` 包含 `id` 和 `title`。它只调用宿主的手动区域长截图能力，不接受脚本、输入模拟或自定义采集程序。官方 `mewu.scroll` 随安装启用；停用、卸载或版本变化取消在途采集，已完成图片属于会话文档并保留。成品沿用原选区标识，可继续绘制、识别文字、复制及引用。

`selection.workflow` 必须包含 `id`、`title`、`prompt`、`accepts: ["image"]`。用户在当前选区执行后，宿主把该选区（包括绘制）作为这一轮图片，使用当前连接继续当前会话；原草稿和未发送引用保留。提示词作为实际用户消息持久保存。该轮不向模型授予记忆或 MCP 工具。不会在安装、打开设置、选择会话时自行发送图片。

`selection.drawing-tools` 包含 `id`、`title` 和 `tools`，允许 `pen`（画笔）、`line`（直线）、`arrow`（箭头）、`rect`（矩形）、`ellipse`（椭圆）、`text`（文字）、`highlighter`（荧光笔）、`number`（序号）、`mosaic`（马赛克），每个工具集包含 1 至 9 个不重复的工具。旧版仅声明五种工具的外部插件仍兼容，不会自动获得未声明的工具。参考[绘图工具集示例](examples/drawing-tools/mewu-plugin.json)。宿主提供持久图层、撤销/重做和原图像素坐标。停用、卸载或更新会使旧绘制操作失效，既有图层仍能显示、复制和导出。

`selection.ocr` 包含 `id`、`title` 和 `engine: "windows"`。用户明确执行后，由宿主合成当前选区（包括标注），调用 Windows 本机 OCR，不使用模型连接。它调用系统已安装的识别语言；不会下载语言包或发送图片到云端。目前不能通过此字段指定可执行文件、自定义引擎或远程服务。识别结果随会话保存，修改图层或选区几何后失效；停用、卸载和更新取消未完成任务，但保留已保存的文字。词框坐标为裁剪图像素，按 `textAngle` 绕图像中心顺时针旋转以映射到原图。

包 `id` 用小写字母开头，只含小写字母、数字、点和短横线，最长 80 字节。`mewu.` 保留给宿主内置包；`publisher` 仅为作者声明，不能取得官方标识。`schemaVersion` 与 `hostApi` 目前均为 1。未识别字段被拒绝。

`license` 必须声明为当前支持的单项 SPDX 标识：`MIT`、`Apache-2.0`、`BSD-2-Clause`、`BSD-3-Clause`、`ISC`、`CC0-1.0` 或 `MPL-2.0`。此字段是作者的许可声明，不是宿主替作者核实版权。版本使用小写 SemVer；标识不能包含空的点分段或 Windows 保留设备名。

## 社区目录

用户可在插件页配置一个公开 GitHub 仓库或目录 JSON 的 blob 链接；仓库地址默认读取根目录 `mewu-catalog.json`。格式如下：

```json
{
  "schemaVersion": 1,
  "plugins": [
    {
      "manifest": { "这里放完整的插件清单": "与开发者发行文件一致" },
      "source": {
        "type": "github",
        "repository": "OWNER/REPO",
        "commit": "完整的40位提交标识",
        "path": "mewu-plugin.json"
      }
    }
  ]
}
```

上面是格式说明，不是可安装示例。目录最多 256 项、2 MiB；必须使用完整提交，不允许 `official`、本地路径、安装状态或重复 ID。条目只是发现信息，安装前仍重新读取指定提交的实际插件并展示详情。目录维护者可采用每个插件一个条目、PR 审阅与 CI 验证，再合并为此 JSON。当前仓库没有发布公共社区目录；未配置目录时只展示真实内置包。

## 历史屏幕录制插件归并

早期版本曾将 `mewu.video-trim`、`mewu.recording-audio`、`mewu.gif` 归并为一个官方包。当前屏幕录制、声音、裁剪和 GIF 导出均为核心能力；启动不会再次执行此归并，也不会修改旧插件记录。

历史迁移曾把原注册记录归档至 `migration.recording-bundle.v1`，并保留旧包文件。已有资料继续保留；`migrations/` 中的旧清单不进入当前官方目录。

现存录音偏好文件不重写，也不把旧插件授权替换为新包授权。归并后的有效声源为静音，用户需重新选择声源；重新启用不会恢复过期的麦克风许可。

## 状态与恢复

插件注册表使用独立 SQLite；文件操作先持久化恢复日志，再提交注册表。安装失败不会静默标记成功。版本更新保留停用状态，可恢复上一版本。更新来源不能跨仓库或文件路径替换现有标识；确需换源时先卸载。卸载保留墓碑，防止应用升级重新启用。

启停和卸载带修订号检查。停用、卸载和版本切换会取消对应插件仍在运行的选区工作流，其他会话运行不受影响。完成的输出与用户文档保留。插件目录及来源配置不包含连接密钥。

此格式的能力边界不等于通用可执行插件沙箱。后续可执行扩展需要单独的权限、进程、版本和兼容性契约。

## 模块标签

API 1 清单可添加 `tags` 数组，允许以下唯一值（最多 16 个）：

`agi`、`ui-enhancement`、`billing`、`themes`、`model-providers`、`messaging`、`memory`、`tools`、`system`、`vision`、`audio`、`documents`、`skills`、`automation`、`privacy`、`entertainment`。

插件市场分别显示为 AGI、UI 增强、用量计费、主题外观、模型与渠道接入、通讯渠道接入、记忆、工具与能力、系统操作、视觉与多模态、语音与音频、文档与渲染、技能包、工作流与自动化、安全与隐私权限、娱乐。分类可用于筛选和搜索；标签不授予能力或运行权限。没有标签的旧清单按现有贡献点显示对应分类，宿主不改写其包文件。未知值、重复值和非数组均拒绝。清单示例：`"tags": ["vision", "documents"]`。

## 模型接入

`model.connection` 提供“API 连接 → 添加”中的实际连接模板。宿主从完整、已启用的安装包读取；停用、卸载、损坏或更新后即刻刷新添加列表。已保存的连接、凭据、默认连接和会话绑定是用户配置，插件生命周期不修改它们，已保存的连接仍由宿主原有三协议内核运行。

每个贡献包含 `id`、`title` 和 `template`，`template` 严格包含：`providerId`、`group`（`china` / `global` / `custom`）、`baseUrl`、`model`、可选的 `searchTerms`、`advanced`。`advanced` 只支持：`protocol`（`chat_completions` / `anthropic_messages` / `openai_responses`）、`authMode`（`bearer` / `api_key` / `none`）、可选的站内 `requestPath`、`requestParameters`（`temperature`、`top_p`、`service_tier`）。限制与连接编辑器一致；Anthropic 的 temperature 不超过 1，不能选择 priority。远端须为无凭据、查询参数和片段的 HTTPS 地址；HTTP 仅允许本机。空地址只允许自定义模板，用户保存前必须填写。清单不能携带密钥、凭据引用、headers、脚本、命令、提示词、自动执行或覆盖会话的数据。

18 个官方包提供原有 23 个模板，同一服务商国内/国际或 API 协议变体放在同一个包。保留原有服务商标识；第三方模板创建连接时使用宿主按插件与贡献标识生成的稳定命名空间，不能覆盖其他模板。更新模板只影响后续新建连接，不更新已有连接。安装和启用不会联网、测试密钥或调用模型；模型列表读取和测试继续由用户明确发起。

参考 [连接模板示例](examples/model-connection/mewu-plugin.json)。这是一种受限声明式扩展，使用宿主已经实现的三种 API 协议；不能由此声明 Hermes、Codex 或其他 Agent 的专用运行协议已经接入。
