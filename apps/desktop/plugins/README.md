# 官方内置模块

本目录是宿主随安装提供的固定功能与模型模板，以及读取历史用户选择所需的迁移证据。它不是第三方插件格式，不接受本地或 GitHub JSON 声明包。内置模块仍可在插件页启用、停用、卸载和恢复；截图绘制与屏幕录制属于核心功能。

第三方插件统一通过 [Mewu API 与 SDK](../../../packages/sdk/README.md) 开发，用独立 JavaScript 包注册 Agent、记忆、工具、模型、通讯渠道和界面能力，通过 [GitHub 社区市场](https://github.com/abnste/mewu-plugins) 安装。

历史声明包记录保留用于数据审计和数据目录迁移，不进入能力授权快照，也不能运行或通过旧接口重新安装。原来的 API 连接、会话和官方模块开关保持原有数据。
