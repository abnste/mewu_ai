# 交互对象

1. 用 `skill_read` 读取本技能实际文件 `references/runtime.md`，以其中的运行契约为准。技能只提供流程，不授予新工具或权限。
2. 根据用户提供的截图、文件和需求生成对象。用户说“放在桌面上”表示 Mewu 中的悬浮呈现，只有明确的文件操作才访问本机目录。
3. 生成一个完整、自包含的最终对象。根节点、脚本位置和事件查询应匹配；把交互状态保存在闭包中，不调用被沙箱禁止的存储、网络或宿主接口。可选音效失败时仍应能点击和更新画面。
4. 使用当前提供的真实验证能力检查交互。收到错误或“点击无反应”的反馈时，先检查初始化异常、DOM 查询和事件绑定，修正源代码；不要重复生成没有改变的错误内容。
5. 用户未要求解释时只返回最终对象代码。没有实际运行过就不要声称已经通过页面测试；不为一次对象创作新建插件。
